VIEW & EARN — MOBILE STARTER
=============================

یہ ایک PWA starter ہے۔ اسے موبائل browser سے چلایا جا سکتا ہے اور compatible browsers میں Home Screen پر install کیا جا سکتا ہے۔

1) تمام files ایک ہی folder میں رکھیں۔
2) logo.png بھی اسی folder میں رکھیں۔
3) کسی HTTPS hosting پر upload کریں (مثلاً GitHub Pages/Cloudflare Pages وغیرہ)۔
4) website کا URL موبائل Chrome میں کھولیں۔
5) Add to Home Screen سے app جیسا install کریں۔

اہم:
- موجودہ code صرف FRONT-END DEMO ہے۔
- حقیقی users، secure login، database، admin approval، notifications اور payment verification کے لیے backend/database لگانا ضروری ہے۔
- Payment کو خودکار طور پر approve نہ کریں؛ server-side verification اور admin approval رکھیں۔
- Guaranteed financial return/earning claims استعمال نہ کریں۔
- Production سے پہلے اپنے payment provider، advertising provider اور مقامی قانونی تقاضے ضرور چیک کریں۔
